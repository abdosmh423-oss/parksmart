# ParkSmart 🚗
A smart parking management system built for real-time space tracking and reservations. 

## 🌟 Live Demo
[Click here to view the live website](https://parksmart-gamma.vercel.app)

## 🚀 Features (MVP)
* **Secure Authentication:** User registration and login.
* **Live Dashboard:** Real-time visibility of available and occupied parking spaces.
* **Reservation System:** Simulated checkout process that instantly updates database availability.
* **Admin Control Center:** Dashboard for system administrators to track total capacity and provision new parking zones.

## 💻 Tech Stack
* **Frontend/Backend:** Next.js (React) & TypeScript
* **Styling:** Tailwind CSS
* **Database & Auth:** Supabase (PostgreSQL)
* **Deployment:** Vercel

## 📂 Architecture Note
This MVP satisfies the core business requirements (BR-01, BR-02, BR-09, BR-11, BR-13, BR-14) outlined in the ParkSmart Software Engineering Specification.
